  EXACT COMMANDS TO PUSH YOUR CODE
═══════════════════════════════════════════════════════════════

Repository: https://github.com/aryandwivedi-224/E-learning-Management-System-.git

═══════════════════════════════════════════════════════════════
METHOD 1: Using Git Bash (Recommended)
═══════════════════════════════════════════════════════════════

1. Right-click in your project folder
2. Select "Git Bash Here"
3. Run these commands:

   git add .
   git commit -m "Add Render deployment configuration"
   git push origin master

   (If branch is 'main' instead of 'master', use: git push origin main)

═══════════════════════════════════════════════════════════════
METHOD 2: Using PowerShell/CMD
═══════════════════════════════════════════════════════════════

1. Open PowerShell or CMD in your project folder
2. Run: .\push-to-github-simple.bat

   OR manually run:

   git add .
   git commit -m "Add Render deployment configuration"
   git push origin master

═══════════════════════════════════════════════════════════════
METHOD 3: Using GitHub Desktop
═══════════════════════════════════════════════════════════════

1. Open GitHub Desktop
2. File → Add Local Repository
3. Select this folder
4. It should detect your existing repo
5. Write commit message: "Add Render deployment configuration"
6. Click "Commit to master"
7. Click "Push origin"

═══════════════════════════════════════════════════════════════

Option C: Use GitHub Desktop
  Download: https://desktop.github.com/
  No command line needed!
